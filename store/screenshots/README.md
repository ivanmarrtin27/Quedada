# Capturas para Google Play / docs

Play exige **mínimo 2** capturas de teléfono (recomendado 4–6). **Solo modo Suave** — nada de Picante en pantalla.

## Archivos en este carpeta

| Archivo | Pantalla |
|---------|----------|
| `01-home.png` | Home + logo + lista de juegos |
| `02-preferencias.png` | Qué Prefieres (duelo A/B, categoría Clásico) |
| `03-impostor.png` | Impostor — setup del lobby |
| `04-yo-nunca.png` | Yo Nunca — carta en modo Suave |
| `05-ajustes.png` | Ajustes |

> **Origen:** capturas reales de dispositivo (iOS), no mockups. Modo Suave / Clásico donde aplica.

## Cómo actualizar capturas

1. Recorré la app en modo **Suave**.
2. Sacá capturas en el dispositivo.
3. Sobreescribí los PNG de arriba con los mismos nombres.
